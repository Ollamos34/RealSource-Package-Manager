# REAL·SOURCE — Package Manager

Простой desktop-менеджер программ для Windows на базе winget.
Позволяет искать, устанавливать, удалять и обновлять программы через
удобный графический интерфейс — без командной строки.

## Возможности

- 🔍 Поиск программ по названию (через winget search)
- ⬇️ Установка одним кликом
- 📦 Список всех установленных программ
- 🔄 Проверка и установка обновлений
- 🖥 Лог выполнения команд прямо в приложении

## Требования

- Windows 10/11
- Установленный App Installer / winget (по умолчанию уже есть на Windows 11
  и современных сборках Windows 10; если нет — поставить из
  [Microsoft Store](https://apps.microsoft.com/detail/9nblggh4nns1))
- [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) —
  только если запускаете уже готовый .exe, а не собираете сами

## Как скачать и запустить

### Вариант 1 — готовый .zip (проще всего)
Зайдите в раздел [Releases](../../releases) этого репозитория, скачайте 
последнюю версию `RealSource-v1.0-win64.zip `распакуйте куда вам удобно и запустите — установка не требуется.

### Вариант 2 — собрать из исходников
1. Установите [Visual Studio 2022](https://visualstudio.microsoft.com/) с
   компонентом .NET desktop development.
2. Скачайте код: кнопка Code → Download ZIP на этой странице
   (или `git clone` для тех, кто знаком с Git).
3. Откройте RealSource.sln в Visual Studio.
4. Нажмите F5 — приложение соберётся и запустится.
